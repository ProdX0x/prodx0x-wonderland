Placez ici vos captures JPG/PNG/WebP et vos vidéos MP4/WebM.
Dans src/apps.js, utilisez par exemple image: 'assets/iris.jpg' et video: 'assets/iris-preview.mp4'.
Si aucun média n’est fourni, l’écran de démonstration est généré localement avec Canvas.
Format conseillé : portrait pour iPhone/iPad, paysage 16:10 pour Mac/TV.
Les médias sont recadrés au centre pour remplir l’écran. Les vidéos sont muettes et en boucle.
