# Assets artistiques V2

Créés avec l’outil intégré `image_gen`, en mode natif, pour ce projet. Aucun appel de secours via API/clé personnelle.
La référence `../reference-target.jpg` a été examinée puis utilisée comme référence artistique pour la vallée ; elle n’est jamais utilisée directement comme fond du site.

Fichiers utilisés à l’exécution :

- `valley.jpg` — panorama 1536 × 1024 ; sky, horizon, montagnes, vallées, cascades, architecture lointaine. Version JPEG optimisée du master.
- `cliff-garden.png` — îlot 1122 × 1402 avec vrai canal alpha, végétation, falaises et cascades. Réutilisé comme plan à plusieurs profondeurs dans le monde.
- `iris-screen-original.png` — écran fictif Iris 852 × 1846. Le PNG est utilisé pour conserver les zones transparentes et éviter un fond blanc dans les parties sombres. Les médias personnalisés du catalogue restent prioritaires.

Masters et essai conservés, non téléchargés par la page : `valley-original.png`, `iris-screen.jpg` (conversion JPEG abandonnée car l’alpha devenait blanc).

Les prompts de production sont consignés dans `../../docs/V2-ASSET-PROMPTS.md`.
