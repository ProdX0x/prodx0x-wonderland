Pensée pour Apple TV

GramGramTV ne transpose pas simplement une application mobile sur un téléviseur.

Son interface est conçue pour le grand écran, le moteur de focus tvOS et la Siri Remote.

  • Navigation optimisée pour la Siri Remote
  • Interface lisible à distance
  • Navigation native tvOS
  • Lecture multimédia sur grand écran

Confidentialité et transparence

GramGramTV utilise votre propre compte Telegram afin de vous donner accès aux contenus auxquels vous êtes autorisé.

Certaines fonctions peuvent également utiliser des services externes nécessaires à l’affichage ou à l’enrichissement des contenus.

  • Connexion à votre propre compte
  • Authentification Telegram par QR code
  • Pas de réseau publicitaire intégré
  • Politique de confidentialité accessible
