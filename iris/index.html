Iris

Un jeu contrôlé par le regard. Ce que vous regardez s'éloigne.

Des lueurs flottent dans le noir, et chacune attend son iris. Les regarder droit dessus les chasse : pour les guider, il faut poser les yeux à côté.

Iris est un jeu d'adresse, d'observation et de contrôle du regard.

Ce qu'il faut pour jouer

  • Iris demande un iPhone sur lequel le suivi facial ARKit est disponible.
  • Si le suivi facial ARKit n'est pas disponible sur l'appareil, Iris indique que le contrôle par le regard est indisponible, au lieu de lancer la calibration du regard.
  • Le jeu se joue en orientation portrait.
  • Pour un meilleur suivi, tenez l'iPhone à hauteur des yeux, à une distance confortable, dans une lumière régulière.

Premier lancement

Les écrans d'introduction expliquent l'interaction par le regard. Vous pouvez revoir ces explications à tout moment par « Comment jouer », depuis l'écran d'accueil ou les réglages.

L'autorisation d'accès à la caméra est demandée lorsque Iris a besoin de la caméra frontale pour le jeu au regard.

Calibration

Une courte calibration adapte le contrôle par le regard à votre façon de regarder l'écran.

Vous pouvez la refaire à tout moment depuis Réglages → Recalibrer le regard.

Si le suivi facial devient temporairement indisponible pendant une partie, l'interaction par le regard peut se mettre en pause jusqu'à ce que le suivi redevienne disponible.

Chapitres gratuits et jeu complet

  • Les chapitres I, II et III — 19 niveaux sur 82 — se jouent sans aucun achat.
  • Iris — Full Game ouvre les chapitres IV à XII.
  • L'achat Iris — Full Game est un achat unique et ne se renouvelle pas.
  • Le prix affiché pour Full Game est fourni et mis en forme par l'App Store pour votre boutique.
  • « Restaurer mes achats » est disponible depuis l'écran d'accès complet et depuis les réglages.

Accès promotionnel

Un accès promotionnel temporaire peut être accordé par un code d'accès Apple (Offer Code).

Iris Promotional Access n'est pas proposé à l'achat direct dans Iris.

Si l'échange d'un code est possible sur votre appareil, choisissez « Utiliser un code d'accès » depuis l'écran d'accès complet. Iris ouvre alors l'interface d'échange de code d'Apple.

Apple prend en charge l'échange. Iris ne lit pas le code, ne le conserve pas et ne le valide pas lui-même. Une fois l'opération terminée du côté d'Apple, Iris relit le droit d'accès auprès de StoreKit et reconnaît l'accès temporaire.

À la fin d'un accès promotionnel temporaire, votre progression est conservée. Les chapitres qui demandent un accès se reverrouillent, sauf si un autre droit d'accès valide existe.

Appareils non pris en charge

Si le suivi facial ARKit n'est pas disponible sur un appareil, Iris indique que le contrôle par le regard est indisponible et n'y ouvre aucune nouvelle acquisition liée au regard.

Les droits d'accès déjà obtenus restent reconnus, et « Restaurer mes achats » reste disponible.
